1 · Cut the cable — mid-answer provider failure

Streams an answer through the fallback cascade (POST /answer/stream). Text is shaded by the tier that wrote it. ✂ Cut kills the primary model's real stream after N chunks — the next tier continues in the same HTTP connection. Cut three times in a row and the primary's circuit opens; the next normal request skips it. Requires the gateway to run with CHAOS_ENABLED=true.

2 · Semantic cache — same question, near-instant second time

Sends the ticket through the full swarm (POST /analyze). Ask, then ask again (or reword it): the second time is served from the cache. Tickets naming a student ID or containing an email/phone are never cached (privacy) — try "my ID is S1002" to see a bypass.

3 · Live agent stream — the swarm working, event by event

Streams one swarm turn as typed Server-Sent Events (POST /analyze/stream): handoffs, each specialist's tool calls while it runs, approval pauses, the final answer. Times are measured in this browser as events arrive. Afterwards, open Phoenix to see the same turn as a trace tree.
